## Decisions carried into implementation

- JetStream and a Postgres outbox.
- Three physical attempts for safe devices; exponential backoff; separate status
  recovery lasting beyond the configured hang, with no repeated liquid handling.
- Preserve actual outcomes during cancellation and expose unresolved work as running.
- A durable local spool; explicit loss when completed measurement bytes cannot be
  recovered; no silent replacement read.
- One executor and one adapter per device, with concurrent workflow runs.
- GraphQL create/start/cancel mutations, attempt/data history, unpaginated listing
  and polling. The read-only proposal was reversed to meet the README.
- Disposable databases, small tested commits, extended driver-kill chaos support,
  isolated test resources, routine plus extended suites, and fail-fast execution.

## Work recorded in Git

Test and implementation commits cover protocol/retry policy, spool ownership and
persistence, transactional dispatch, driver execution/data capture, GraphQL, and
the system harness. Further regressions cover data verification, cancellation
backoff, outbox rollback, lost bytes, conflicting evidence, late timeout resolution,
subscription startup failure, and non-replayed mutation requests.

The executor stores a run and its scheduling projection in one JSON aggregate,
with separate attempts/reservations/outbox/inbox tables. This implementation choice
and its consistency rationale are documented in NOTES.md.

Go unit checks, coverage inspection, vet and containerized Go 1.26 race checks have
also run. The extended fault campaign is being completed, preserving failed attempts
and recording unexecuted scenarios as not run.

The campaign exposed test-harness setup/readiness/port issues as well as application
issues. Each fix has a corresponding test or targeted rerun. Detailed evidence,
exact commands, seeds, application fingerprint, final scenario results, and limits
are recorded in `docs/validation.md` and NOTES.md.

Passing fault cases were retained while the runner was corrected to retry read-only
GraphQL requests. Mutations remain unretried after an uncertain response. The
application source was fingerprinted to verify that retained and resumed campaign
segments exercise the same implementation; Go module direct/indirect annotations
were normalized while preserving every pinned dependency version.
